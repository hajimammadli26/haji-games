Azərbaycan dili

"Cırtdan: Köhnə Bakıda Qaçış" bütün yaşlar üçün oyundur. Biz oyunçuların məxfiliyinə hörmət edirik və imkan qədər az məlumat toplayırıq.

Qısaca:

  • Reklam yoxdur. Oyundaxili satınalma yoxdur.
  • Hesab yoxdur. Ad, e-poçt, telefon, şəkil, yer (məkan) və ya kontakt soruşmuruq.
  • İzləmə yoxdur: analitika, reklam identifikatoru və üçüncü tərəf izləmə alətləri istifadə olunmur.
  • Oyunun gedişatı (rekord, çörək, personajlar, ayarlar) yalnız cihazın özündə saxlanılır.

Onlayn liderlər cədvəli (könüllü). Oyunçu özü ləqəb seçərsə və bu funksiya açıqdırsa, ən yaxşı nəticə liderlər cədvəlinə göndərilir. Göndərilənlər yalnız bunlardır:

  • hazır siyahıdan seçilmiş ləqəb (sifət + qəhrəman, məsələn, "Cəld Simurq"); oyunçu öz adını yaza bilməz;
  • xal, qaçılan məsafə və oyundakı şəhər (oyunçunun real yeri deyil);
  • cihazda yaradılan təsadüfi nömrə (oyunçunun öz nəticəsini tanımaq üçün). Bu nömrə telefonla, reklam identifikatoru ilə və ya şəxslə əlaqəli deyil.

Bu məlumatlar yalnız liderlər cədvəlini göstərmək üçün istifadə olunur. Satılmır, reklam üçün istifadə olunmur və heç kimlə paylaşılmır. Server Cloudflare xidmətində işləyir. Sorğunu çatdırmaq üçün Cloudflare IP ünvanını görür, lakin biz IP ünvanını saxlamırıq. Məlumat şifrələnmiş (HTTPS) bağlantı ilə göndərilir.

Necə söndürmək olar: oyunda Ayarlar → Onlayn liderlər → Bağlı. Söndürüləndən sonra heç nə göndərilmir. Ləqəb seçilməyibsə, onsuz da heç nə göndərilmir.

Silmək: nəticənin silinməsini istəyirsinizsə, [OWNER EMAIL] ünvanına ləqəbi və təxmini xalı yazın, onu siləcəyik. Oyunu cihazdan silmək cihazdakı bütün məlumatları silir.

Uşaqlar haqqında. Oyun uşaqlar üçün nəzərdə tutulmayıb, bütün yaşlar üçündür. Biz 13 yaşdan kiçik uşaqlardan bilərəkdən şəxsi məlumat toplamırıq. Liderlər cədvəli heç bir şəxsi məlumat göndərmir, yalnız yuxarıda sadalananları göndərir. Valideyn uşağın nəticəsi ilə bağlı sual verə, onun silinməsini istəyə və ya liderlər cədvəlini Ayarlar bölməsindən söndürə bilər.

İcazələr. Oyun yalnız liderlər cədvəli üçün internet icazəsindən istifadə edir. Kamera, mikrofon, yer və kontaktlara giriş istəmir.

Dəyişikliklər. Bu siyasət dəyişsə, yeni versiyanı bu səhifədə yeni tarixlə dərc edəcəyik.

English

"Cırtdan: Köhnə Bakıda Qaçış" is a game for players of all ages. We respect your privacy and collect as little as possible.

In short:

  • No ads. No in-app purchases.
  • No accounts. We never ask for a name, email, phone number, photo, location or contacts.
  • No tracking: no analytics, no advertising ID, no third-party tracking tools.
  • Game progress (best score, bread, characters, settings) is stored only on the device.

Online leaderboard (optional). If the player picks a nickname and the feature is on, their best result is sent to the leaderboard. Only this is sent:

  • a nickname chosen from a fixed list (adjective + hero, e.g. "Cəld Simurq"); players cannot type their own name;
  • the score, the distance run and the in-game city (not the player's real location);
  • a random number made on the device, so the game can recognise the player's own entry. It is not linked to the phone, the advertising ID or the person.

This data is used only to show the leaderboard. It is never sold, never used for advertising and never shared with anyone. The server runs on Cloudflare. Cloudflare sees the IP address in order to deliver the request, but we do not store it. Data is sent over an encrypted (HTTPS) connection.

How to turn it off: in the game, Ayarlar (Settings) → Onlayn liderlər → Bağlı (Off). After that, nothing is sent. If no nickname has been chosen, nothing is sent anyway.

Deletion: to have a leaderboard entry removed, email [OWNER EMAIL] with the nickname and the approximate score, and we will delete it. Uninstalling the game deletes everything stored on the device.

Children. The game is made for a general audience, not specifically for children. We do not knowingly collect personal information from children under 13. The leaderboard sends no personal information, only the items listed above. A parent or guardian can ask about their child's leaderboard entry, ask for it to be deleted, or turn the leaderboard off in Ayarlar (Settings).

Permissions. The game uses the internet permission only for the leaderboard. It does not ask for the camera, microphone, location or contacts.

Changes. If this policy changes, we will publish the new version on this page with a new date.
