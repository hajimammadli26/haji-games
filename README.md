# Haji Games

Oyun layihəsi. Claude Code agent studiyası ilə qurulub.

## Agentlər

Bu layihədə [Claude Code Game Studios](https://github.com/Donchitos/Claude-Code-Game-Studios) şablonu var (MIT lisenziyası, bax `LICENSE-Claude-Code-Game-Studios`):
49 agent (`.claude/agents/`), 78 skill (`.claude/skills/`), qaydalar və skriptlər.

## Başlamaq

Claude Code-u bu qovluğun kökündə aç və yaz:

- `/start` — haradan başlayacağını soruşur və yol göstərir
- `/prototype <oyun ideyası>` — ideyadan oynana bilən prototip
- `/brainstorm` — oyun ideyaları
- `/next-step` — növbəti addım
